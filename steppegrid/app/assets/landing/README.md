# Landing-page photos

These photographs show renewable-energy infrastructure elsewhere in Kazakhstan
for visual context. Neither depicts Shamshi Kaldayakova or an installed system
from the SteppeGrid model.

- `korday-wind.jpg`: **Korday wind farm near Moozbel village, Kazakhstan**,
  by **МаратД**, 14 August 2016.
  [Source](https://commons.wikimedia.org/wiki/File:Korday_wind_farm_near_Moozbel_village,_Kazakhstan.jpg).
- `qonaev-solar.jpg`: **Kapshagay solar power plant, Qonaev, Kazakhstan**,
  by **Nikolai Bulykin**, 5 May 2023.
  [Source](https://commons.wikimedia.org/wiki/File:Конаев,_СЭС_сверху.jpg).

Both photographs are used under
[Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).
Photo assets retain that license, independently of the code's MIT license.
Public image copies were downloaded through an image-delivery proxy because the
original media host was unreachable from the development environment. The proxy
re-encodes the copies. The solar
image uses Wikimedia's 1,280-pixel thumbnail; the web layout displays cropped
views through CSS. Attribution and source/license links also appear on the page.

All displayed planning statistics and chart series come from the existing saved
Shamshi Kaldayakova scenarios, using the illustrative 500 MWh/year demand
estimate and 2025 ERA5 weather. No optimization runs on landing-page views.
