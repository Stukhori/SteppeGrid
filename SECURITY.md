# Security Policy

## Supported version

Security fixes are provided for the latest release on the `main` branch.

| Version | Supported |
|---|---|
| 1.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use
[GitHub's private vulnerability reporting](https://github.com/Stukhori/SteppeGrid/security/advisories/new)
and include:

- the affected component and version;
- steps to reproduce the issue;
- the potential impact;
- any suggested mitigation.

Avoid including real credentials, personal information, or sensitive datasets
in the report. You should receive an acknowledgement after the report has been
reviewed. Public disclosure should wait until a fix or mitigation is available.

SteppeGrid is a planning and research tool. Security reports do not replace the
engineering, procurement, or operational review required for a deployed energy
system.
