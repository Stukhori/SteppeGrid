# Rodina Literature-Derived Benchmark Source

This directory transcribes Table 1 and contextual load statements from the 2026 Rodina agricultural-settlement modelling paper identified in `source_metadata.yaml`.

The monthly rows are preserved exactly as printed. They do not arithmetically agree with every printed annual total. SteppeGrid treats that disagreement as source-integrity evidence and never modifies the transcription to remove it.

The paper does not publish a machine-readable hourly village load series or establish a calendar year for the monthly table. Any hourly output built from these files is a deterministic reconstruction constrained by literature-derived monthly energy, not measured Rodina demand.
